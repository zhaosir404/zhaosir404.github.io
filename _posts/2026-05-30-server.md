尝试租一个服务器跑程序
阿里云有学生认证300 买了半年2g2核的
进入服务器后sudo apt update更新
网页的防火墙和服务器内的ufw还不是一个东西 反正都设置一下 出了默认80和443还开了SSH和8080（我的项目用的端口）
sudo ufw allow OpenSSH
sudo ufw allow 8080/tcp

创建新用户 sudo adduser 用户名
创建新用户是因为总是用root容易有误操作问题 可以模拟实际工程环境
su - 用户名 进行切换
usermod -aG sudo 用户名 给用户sudo命令权限

使用sudo apt 依赖包名 安装环境
启动数据库服务 初始化mysql
之前开了ssh端口 可以用ssh传输文件
scp 本地文件 用户名@服务器IP:服务器目录
端口半天连不上 发现是之前服务器网页端的防火墙没开 也设置一下
