docker pull 镜像名  # 拉取镜像
docker ps  # 查看在跑的容器 -a是包含未运行的容器
docker run -d 镜像名  # 运行容器 镜像名前面加参数选项 后面加容器内部命令
///
-v 宿主机目录：容器目录  # 挂载卷，即宿主机容器使用共享空间，但容器删了实际数据还在
-p 宿主机端口:容器端口
--name 容器名
-e ***=***
-p端口映射 -d后台运行 -e设置环境变量
-it  # -i保持输入 -t创建伪终端
///
docker rm 容器id  # 删除容器
docker rmi 镜像id  # 删除镜像
docker attach 容器id/name  # 窗口切回正在运行的容器
docker start 容器id/name  # 运行一个停止的容器 -ai连接到输入输出
docker exec -it 容器id/name bash  # 给一个正在运行的容器新开一个终端

---
遇到了进入容器后开进程窗口被输出占用的情况 ctrl c会退出进程 怎么保持容器运行的情况退出去？
ctrl p + ctrl q 之后切回去用attach
-it 和 -ai都有点想开终端连接输入输出 前者是创建 后者是连回去 attach不用加参数选项（本身相当于-a）
